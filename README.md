# 📅 나만의 캘린더 (My-Calendar)

> **"종이 스케줄러의 직관성, 정시 알림, 그리고 프로젝트 폴더 바로가기까지 하나로"**  
> 모니터 옆 포스트잇에 적어두고 일하다 회의를 놓칠 뻔하거나, 회의 직전 관련 폴더를 찾느라 허둥댔던 경험에서 출발한 데스크톱 스마트 스케줄러 (macOS & Windows)

---

## 💡 개발 배경 (Why I built this)

업무를 시작할 때 다이어리나 스티커 메모에 **'오늘 할 일'**, **'이번 주 할 일'**을 적어두고 모니터 옆에 붙여둔 채 일하곤 했습니다. 

하지만 일에 한창 몰입해 컴퓨터 화면만 바라보다 보면 두 가지 큰 불편함이 있었습니다:

1. **소리도 알림도 없는 종이 메모**:  
   회의 시간을 놓치지 않으려면 머릿속으로 계속 *'몇 시 회의였지?', '몇 분 남았지?'*를 의식해야 했고, 결국 본업에 쏟아야 할 깊은 몰입이 끊기곤 했습니다.
2. **회의 직전 파일/폴더 찾기의 번거로움**:  
   막상 회의나 업무 시간이 다가왔을 때, 해당 안건과 관련된 프로젝트 폴더나 기획서, 개발 소스를 찾느라 Finder나 윈도우 탐색기를 한참 뒤적거리며 시간을 허비했습니다.

> **"스케줄이나 할 일을 등록할 때 작업 폴더를 미리 묶어둘 순 없을까?  
> 컴퓨터로 일할 때 제때 확실하게 알림을 주고, 카드 클릭 한 번으로 관련 프로젝트 폴더까지 한 번에 바로 열어줄 수 있다면!"**

이 확실한 업무 페인포인트를 해결하기 위해 직접 만들게 되었습니다.

## ✨ 핵심 기능 (Key Features)

### 1. 📂 스케줄 등록 시 프로젝트 폴더 연동 & 원클릭 바로가기 (Core Feature ⭐)
- 새로운 일정이나 할 일을 등록할 때, 해당 업무와 관련된 **로컬 프로젝트 폴더를 함께 선택·등록**할 수 있습니다.
- 등록된 카드에는 귀여운 **미니 포스트잇 폴더 태그**가 생성되며, 클릭 한 번으로 **macOS Finder 또는 Windows 파일 탐색기**가 즉시 열립니다.
- 회의 자료, 디자인 파일, 소스 코드를 찾느라 탐색기 경로를 헤맬 필요 없이 **1초 만에 실작업 환경으로 점프**합니다.

### 2. 🔔 몰입을 방해하지 않는 정시 시스템 알림
- 중요한 회의, 약속, 마감 일정이 다가오면 데스크톱 화면에 명확하게 시스템 알림을 띄워줍니다.
- 더 이상 시계를 힐끔거리며 불안해하지 않고, 하던 일에 100% 온전히 몰입할 수 있습니다.

### 3. 🗂️ 포스트잇의 디지털화: '항상 위' 플로팅 미니 보드
- 다른 작업 창들에 가려지지 않도록 **항상 위 고정(Always-on-Top)** 및 **투명도 조절**을 지원합니다.
- 모니터 한구석에 띄워두고 종이 포스트잇처럼 오늘 할 일과 회의 일정을 실시간으로 체크할 수 있습니다.

### 4. 📊 일주일 일정이 한눈에 보이는 '주간 통합 배너'
- 주간 단위 프로젝트나 할 일을 등록할 때, 달력의 일주일치 칸마다 똑같은 일정이 7번씩 복사되어 지저분해지는 문제를 없앴습니다.
- 날짜 아래 7일(일~토) 전체를 시원하게 가로지르는 **단일 주간 배너 Bar**로 이번 주의 핵심 목표를 직관적으로 파악합니다.

### 5. 🎯 3단계 업무 범위 관리 (오늘 / 이번 주 / 이번 달)
- 긴급한 일과 여유 있는 과업을 분리하여 번아웃 없이 우선순위대로 일정을 소화할 수 있습니다.

### 6. 📝 자유로운 스티커 메모 패드
- 할 일 목록 외에 통화 메모, 아이디어 스케치, 임시 텍스트를 색상별 스티커 메모에 빠르게 기록할 수 있습니다.

### 7. 🔕 깔끔한 상주 모드 (No Dock / Clean Tray)
- 메인 창을 닫아도 **macOS 상단 메뉴바** 및 **Windows 작업표시줄 시스템 트레이**에 조용히 상주하여 필요할 때 단축키나 클릭 한 번으로 즉시 나타납니다.

## 🛠️ 기술 스택 (Tech Stack)

- **macOS Native**: Swift 5.10+, SwiftUI, AppKit (Universal Binary: arm64 + x86_64)
- **Windows Standalone**: Electron 33+, HTML5 / CSS3 / Vanilla JavaScript
- **Cross-Platform Icons**: 윈도우/맥 환경을 가리지 않고 100% 깨짐 없는 렌더링을 보장하는 인라인 벡터 SVG 시스템
