# 📅 나만의 캘린더 (My-Calendar)

> **"종이 스케줄러의 아날로그 직관성과 데스크톱 알림의 편리함을 하나로"**  
> 모니터 옆 포스트잇에 적어두고 일하다 회의를 놓칠 뻔한 경험에서 출발한 데스크톱 스마트 스케줄러 (macOS & Windows)

---

## 💡 개발 배경 (Why I built this)

업무를 시작할 때 다이어리나 스티커 메모에 **'오늘 할 일'**, **'이번 주 할 일'**을 적어두고 모니터 옆에 붙여둔 채 일하곤 했습니다. 

하지만 일에 한창 몰입해 컴퓨터 화면만 바라보다 보면, **종이 메모는 소리를 내거나 알림을 주지 못합니다.**  
회의 시간을 놓치지 않으려면 머릿속으로 계속 *'몇 시 회의였지?', '몇 분 남았지?'*를 끊임없이 신경 써야 했고, 그 때문에 정작 본업에 쏟아야 할 중요한 집중력이 흐트러지기 일쑤였습니다.

> **"손으로 적던 그 익숙하고 가벼운 메모 느낌은 그대로 살리되,  
> 컴퓨터로 일할 때 제때 확실하게 알림을 주고, 모니터 구석에 늘 띄워둘 순 없을까?"**

이 작은 불편함 하나를 제대로 해결하기 위해 직접 만들게 되었습니다.

## ✨ 핵심 기능 (Key Features)

### 1. 🔔 몰입을 방해하지 않는 정시 시스템 알림
- 중요한 회의, 약속, 마감 일정이 다가오면 화면에 명확하게 시스템 알림을 띄워줍니다.
- 더 이상 시계를 힐끔거리며 불안해하지 않고, 하던 일에 100% 온전히 몰입할 수 있습니다.

### 2. 🗂️ 포스트잇의 디지털화: '항상 위' 플로팅 미니 보드
- 다른 작업 창들에 가려지지 않도록 **항상 위 고정(Always-on-Top)** 및 **투명도 조절**을 지원합니다.
- 모니터 한구석에 띄워두고 종이 포스트잇처럼 오늘 할 일과 회의 일정을 실시간으로 체크할 수 있습니다.

### 3. 📊 일주일 일정이 한눈에 보이는 '주간 통합 배너'
- 주간 단위 프로젝트나 할 일을 등록할 때, 달력의 일주일치 칸마다 똑같은 일정이 7번씩 복사되어 지저분해지는 문제를 없앴습니다.
- 날짜 아래 7일(일~토) 전체를 시원하게 가로지르는 **단일 주간 배너 Bar**로 이번 주의 핵심 목표를 직관적으로 파악합니다.

### 4. 📂 프로젝트 작업 폴더 원클릭 바로가기
- 일정 및 할 일 카드에 연결된 작업 폴더(Finder / 윈도우 탐색기)를 클릭 한 번으로 즉시 열 수 있습니다.
- 회의 자료나 프로젝트 소스 폴더를 찾느라 탐색기를 뒤적거리는 시간을 절약해 줍니다.

### 5. 🎯 3단계 업무 범위 관리 (오늘 / 이번 주 / 이번 달)
- 긴급한 일과 여유 있는 과업을 분리하여 번아웃 없이 우선순위대로 일정을 소화할 수 있습니다.

### 6. 📝 자유로운 스티커 메모 패드
- 할 일 목록 외에 통화 메모, 아이디어 스케치, 임시 텍스트를 색상별 스티커 메모에 빠르게 기록할 수 있습니다.

### 7. 🔕 깔끔한 상주 모드 (No Dock / Clean Tray)
- 메인 창을 닫아도 **macOS 상단 메뉴바** 및 **Windows 작업표시줄 시스템 트레이**에 조용히 상주하여 필요할 때 단축키나 클릭 한 번으로 즉시 나타납니다.

## 🛠️ 기술 스택 (Tech Stack)

- **macOS Native**: Swift 5.10+, SwiftUI, AppKit (Universal Binary: arm64 + x86_64)
- **Windows Standalone**: Electron 33+, HTML5 / CSS3 / Vanilla JavaScript
- **Cross-Platform Icons**: 윈도우/맥 환경을 가리지 않고 100% 깨짐 없는 렌더링을 보장하는 인라인 벡터 SVG 시스템
